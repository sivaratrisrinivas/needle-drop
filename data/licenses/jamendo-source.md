## Provenance
Every track in this catalog comes from the MTG-Jamendo dataset. Its audio_licenses.txt file lists, for each track, the Creative Commons license it was published under on Jamendo when the dataset was assembled (2019).

## Limits
That file is a snapshot. Artists can change licenses or remove tracks, so a snapshot license is a verified source for what the track was released under, not proof of today's terms. Before publishing, open the track page on jamendo.com and confirm the license shown there, or run the live check with a Jamendo API client id.

## Dataset copies versus the original
The MTG-Jamendo dataset itself is distributed for non-commercial research only. Use the track you download from jamendo.com under its CC license, not a copy taken from the research dataset.

## Commercial licensing
Jamendo Licensing sells commercial licenses for many tracks in its catalog. Prices are set by Jamendo per use and are not included here; a price is only known after checking jamendo licensing for that track.
